# Homebrew Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to execute
> the filesystem task and review the finished change. Do not commit or push
> without explicit user permission.

**Goal:** Prepare `brew install onejae/tap/mdir` for macOS and Linux, installing
the existing `mdir-fm` executable.

**Architecture:** Keep shared filesystem logic and isolate native operations in
Linux/Darwin files. Generate a checksummed source formula from a published
version tag. CI executes native tests before publication.

**Tech Stack:** Go, golang.org/x/sys/unix, Python standard library, Ruby Homebrew
formula, GitHub Actions.

## 1. Portable filesystem operations

- [x] Identify Linux-specific APIs in `internal/files/{operations,permissions,
  move_cleanup,files}.go` and reproduce the macOS compile failures.
- [x] Implement platform helpers and shared descriptor-relative operations
  without weakening no-follow, no-overwrite, or source/destination verification.
  Preserve mode-000 chmod on Linux and changed-directory protection. On Darwin,
  fail safely when an unreadable inode cannot be pinned for chmod. If newer `os.Root`
  methods are needed, declare the minimum Go version in `go.mod`.
- [x] Adapt the existing permission regression test to use the native descriptor
  helper. Add focused coverage for portable operations and mount discovery.
- [x] Run `go test -race ./internal/files` and compile that package's tests for
  `GOOS=darwin GOARCH=amd64` and `GOARCH=arm64`.

## 2. Application integration

- [x] Update `internal/app/commands.go` to choose `open` on Darwin and `xdg-open`
  on Linux, preserving argument separation.
- [x] Fix the filesystem-size type difference in `internal/app/render.go`; make
  the operating-system banner and `scripts/smoke.py` work on both platforms.
- [x] Add `.github/workflows/ci.yml` for native Linux/macOS tests, vet, build,
  and PTY smoke. Keep CI read-only.

## 3. Homebrew tap preparation

- [x] Add `packaging/homebrew/mdir.rb.in` with a release URL, computed checksum,
  Go build dependency, executable name, and a functional PTY test.
- [x] Add `scripts/homebrew-formula.py` to validate a version tag, fetch its
  archive, compute SHA-256, and output the complete formula.
- [x] Add a tap CI workflow under `packaging/homebrew/` that installs and tests
  the formula on macOS and Linux without publishing anything.
- [x] Document the exact source-tag, formula-generation, tap-layout, and native
  verification steps in `packaging/homebrew/README.md`. Update the root README
  with the intended install/run commands and release-status qualification.

## 4. Verification and review

- [x] Run `make test check build`, `go mod verify`, and
  `python3 scripts/smoke.py` using writable temporary Go caches.
- [x] Cross-compile applications and test binaries for macOS Intel/Apple Silicon
  and build Linux arm64. Inspect generated executable formats.
- [x] Exercise formula generation with a local fixture, including bad-version
  and failed-download handling. Inspect the rendered formula and workflows.
- [x] Review scope, then correctness; fix findings and run relevant checks.
- [x] Run `git diff --check` and report local verification separately from native
  macOS/Homebrew and remote publication status. Request only the final Git and
  publication authorization once the result is concrete.

## Verification record

- Linux `make test check build`, `go mod verify`, and the real PTY smoke passed
  with Go 1.26.2. Independent race-test runs and the scope/correctness reviews
  also passed.
- Application and test binaries compile for Darwin amd64 and arm64. The Linux
  arm64 application builds. Executable-format inspection confirms Mach-O and
  ARM64 ELF outputs respectively.
- Generator fixtures passed checks for the release URL, exact SHA-256, invalid
  tags/archives, mismatched CLI versions, atomic output, and preserving an
  existing formula after failed downloads. Both workflows parse as YAML.
- A temporary Homebrew checkout loaded the generated formula and executed its
  real `fetch` and `install` methods against this checkout with writable Go
  caches. Its `run_test` then passed the version and real PTY tests against the
  formula-built binary. This exposed and fixed a PTY buffer deadlock in the
  test; the corrected test was reviewed again. The temporary formula's archive
  checksum is a fixture and must not be published.
- Native Linux and macOS CI passed on both architectures at commit `01079fe`:
  https://github.com/onejae/mdir/actions/runs/44021491482.
  The initial macOS run exposed two tests that assumed temporary paths had no
  symlink ancestors. Both failures were reproduced on Linux with a symlinked
  `TMPDIR`, then fixed by resolving expected paths without changing tree behavior.
- The user authorized commit, merge, push, release-tag, and tap publication.
  Commit `01079fe` was merged into `main` and tagged `v0.1.0`. The public tap is
  https://github.com/onejae/homebrew-tap. Its formula was generated from the
  published archive, with SHA-256
  `3674297cbc7a4d10bc32374be8ef74966eff28b237e3aa8f0f39bd73371a3ab3`.
- Homebrew installation, terminal tests, and strict formula audits are tracked
  for all four platforms in the tap workflow:
  https://github.com/onejae/homebrew-tap/actions/runs/44022026942.
