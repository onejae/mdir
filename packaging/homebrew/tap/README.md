# onejae's Homebrew tap

Install [mdir-fm](https://github.com/onejae/mdir), a terminal file manager for
macOS and Linux:

```sh
brew install onejae/tap/mdir
mdir-fm
```

The formula builds from a checksummed release archive. Homebrew installs Go as
a build dependency. The package is named `mdir`; its executable is `mdir-fm`.

To update:

```sh
brew update
brew upgrade onejae/tap/mdir
```
